# Figures Directory

This folder contains scripts and data for the creation of publication-quality figures and results visualizations.

## Contents

- **Figure_3_tiles.py**: Python script for generating Figure 3 of tile visualizations.
- **Figure 5.R**: R script for generating Figure 5.
- **predicted_TGI.RData, predicted_skyview.RData, predicted_solar.RData, predicted_solar_sd.RData**: RData files containing predicted Square Errors used in the Figure 5.

## Data Dependencies

- The script in `Figure 5.R` uses outputs generated by code in the `code/statistical_analysis/second_analysis_final_points_models.R` file.

## Usage

1. Make sure you have run all model training and prediction scripts in the main `code` directory.
2. Run the scripts in the `code/statistical_analysis` first to generate Figure 5.

See each script's header for further details and required inputs.
