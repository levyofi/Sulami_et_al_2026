# Predicted Maps Directory

This directory contains model predictions and error maps generated by the testing scripts.

## Contents

- **Zeelim_23.9.19_0610, Zeelim_23.9.19_1510, Zeelim_23.9.19_1700/**: Subdirectories for each map/timepoint containing predicted and error GeoTIFF files.
- **error_maps_model_size_*.csv**: CSV files summarizing error maps for different model patch sizes.
- **model_comparison.csv**: Model comparison results.
- **predicted_size_*.tif, error_size_*.tif**: GeoTIFF files with model predictions and error values for each configuration.

## How Files Are Created and Used

- Files in this directory are generated by `code/stage_4_run_parallel_model_testers.py` and related scripts.
- These outputs are used for further statistical analysis (`code/statistical_analysis`) and for figure generation (`code/Figures`).

## Structure

Each subdirectory contains:

- **predicted_size_* files**: Model predictions for each pixel/patch.
- **error_size_* files**: Error maps corresponding to predictions.

Do not modify these outputs directly; regenerate them by rerunning the appropriate code if needed.
