# Data Directory

This directory contains all input datasets and intermediate data used throughout the modeling pipeline.

## Contents

- **desert_maps.csv**: Main CSV file describing the maps and associated metadata, such as which map is used for training/testing.
- **model_comparison.csv**: Results from model comparisons, generated by the `../code/model_trainer.py` script.
- **submaps_cropped/**: Contains map-specific subdirectories with raw and processed data for model input.

## submaps_cropped Structure

Each subdirectory (e.g., `Zeelim_23.9.19_0610`) contains:

- **GeoTIFF files with variables used for modeling:**
  - `IR_*.tif`: observed ground temperature map. Used for model labeling and validation. 
  - `shade_*.tif`: Shade map indicating shaded areas.
  - `skyview_*.tif`: Sky view factor map.
  - `TGI_*.tif`: Triangular Greenness Index (TGI) map.
  - `slope_*.tif`: Slope map derived from topography.
  - `height_*.tif`: Height (DSM-DTM) map.
  - `solar_*.tif`: Modeled (clean sky) solar radiation map.
  - `real_solar_*.tif`: Real solar radiation map (corrected for clouds using the observed solar radiation from our meteorological station, see `meteorological_data.csv`).

  
- **Intermediate mosaic and DSM files for each map:**
  - `IX-12-11646_*_cropped_downsampled_*.tif`: Intermediate mosaics and Digital Surface Model (DSM) files used in the mapping process.
  
- **Meteorological data:**
  - `meteorological_data.csv`: Meteorological data for the specific flight.
    
## Data Generation and Usage

- The files here are created or consumed by scripts in `../code` (see `stage_1_dataset_creator.py` and related files).
- Processed and augmented data are used as inputs for model training and prediction.
- New files will be generated in this folder as you run the code pipeline.

Do not modify files in this folder manually unless you know what you are doing.
