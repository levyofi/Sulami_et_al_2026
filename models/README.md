# Models Directory

This folder stores trained model files generated by the model training scripts.

## Contents

- **.pth files**: These are PyTorch model checkpoints generated by `code/model_trainer.py` and `code/stage_3_run_parallel_models_trainer.py`. Each file corresponds to the best-performing model for a specific configuration (e.g., patch size, batch size, epochs).

## How Models Are Used

- These models are loaded by the testing scripts (e.g., `code/model_tester.py`, `code/stage_4_run_parallel_model_testers.py`) to generate predictions, which are then saved in `../predicted_maps`.

## Naming Convention

- Files are named according to their architecture and training parameters for easy identification.

Do not edit or delete these files unless retraining models.
